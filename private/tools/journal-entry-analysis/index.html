JOURNAL ENTRY ANALYSIS

从序时账到可复核的凭证结论。

上传 .xls / .xlsx，确认工作表、表头与字段映射，系统在后台完成清洗、凭证汇总、业务分类、对方科目与异常凭证分析。原始文件不会被修改；结果和导出文件仅归属于当前登录用户。

v1.3.4 更新说明
  • 完整分析报告新增“配置完整分析报告”：标准序时账 Sheet 可使用网页选择的行和列，其他分析 Sheet 保持不变。
  • 新增“导出数据预览工作台”：在网页中查看即将导出的真实行和列，支持服务器分页、列选择与手工排除行。
  • 新增单文件 / 批量合并“标准序时账导出预览”，可选择列、排除行后再导出。
  • 修改筛选条件会清空手工行选择并提示；拆分模板不保存具体行选择。
  • 拆分导出新增“导出列设置”：可选择财务、辅助核算、来源与系统追溯字段，并调整列顺序。
  • 预览会基于筛选后的数据检测空白列，支持推荐列、取消空列、全选和恢复默认；多 Sheet 与 ZIP 使用统一列结构。
  • 单文件标准序时账与批量合并序时账默认改为中文业务列优先，技术追溯字段移至末尾。
  • 结果页改为轻量索引 + 服务器分页：浏览器不再下载完整 result.json。
  • 凭证明细、业务分类、对方科目和异常发现按需加载；大型结果首屏独立于完整结果大小。
  • 新增 300k 行结果浏览验证；历史小任务会自动生成轻量索引，超大历史任务需重新分析。
  • 新增“批量分析”工作台：一次上传最多 20 个 Excel，逐文件配置后统一开始。
  • 每个文件仍使用独立子任务、独立结果与独立 Excel 报告，不合并跨文件数据。
  • 新增批量进度、逐文件状态、批量历史与单文件配置入口。
  • 新增“筛选与拆分导出”：先筛选、再按科目/客户/供应商/月份等拆分，支持多 Sheet 或 ZIP。
  • 新增安全删除与保留策略：可删除单文件任务/批次/拆分输出；过期输出提示重新生成。
  • 大批量报告/拆分导出改为后台生成，页面轮询进度；失败会显示原因并清理临时文件。
  • 修复分析完成瞬间结果尚未落盘时偶发“结果尚未生成”。
  • 优化大文件上传检查，接近 25 MB 的文件也能快速完成工作表识别。
