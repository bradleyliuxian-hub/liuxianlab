PURCHASE & RETURNS RECONCILIATION

把正负流水，按业务键与 FIFO 对干净。

上传 SAP 采购收货、退货/冲销的正负数量明细，系统按供应商、采购订单、行项目、物料、单位与单价构建业务键，在同一业务键内按送货日期和原始行号执行 FIFO。原始文件不会被修改；每条结果保留原始行号，导出文件仅归属于当前登录用户。

03

对抵规则

同一业务键内正负数量互抵；方向只由数量正负决定，移动类型用于审计。

DEFAULT

匹配字段 必须全部一致

不跨采购订单、行项目、物料、单位或单价凑金额。

排序与方式

  1. 1送货日期 ASC
  2. 2原始 Excel 行号 ASC
FIFO先进先出；日期相同按原始行号稳定排序

剩余与金额

正向剩余 = 原数量 − 已对抵；负向剩余 = 原数量 + 已对抵。

剩余金额按原始金额同比例分摊，不重新猜测价格。

高级设置（V1 固定）

V1 固定使用默认匹配键与 FIFO。后端已抽象 ReconciliationConfig，后续可扩展自定义匹配键、日期优先级、LIFO、金额与数量容差，而无需重写引擎。

处理约 35,000 行时通常需要数秒；关闭页面后任务仍会继续。
