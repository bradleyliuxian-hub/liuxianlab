EXCEL DECIMAL CHECK

检查并定位超过两位小数的单元格。

文件在你的浏览器中读取、扫描与生成，不会上传到服务器。原文件不会被修改。工具检查的是单元格 实际数值而非显示格式，因此「实际值 1.23456、显示 1.23」仍会被判为异常； 尾随 0 不会误报，JS 浮点误差也不会误报。网页内可直接定位复核，也可导出带 Excel F5 定位地址的问题清单， 或导出仅将问题单元格标黄的原始副本对比文件。

VERSION HISTORY

版本迭代

  • v1.2.0

    改为只读复核 + 标黄对比：不再自动修正、不再导出修正版 Excel，也移除「处理状态」；网页内只读展示原始工作簿并标黄问题单元格；新增「下载标黄对比文件」——基于原始文件的最小 OOXML 样式补丁（与死数检查一致）。

  • v1.1.1

    Viewer 显示原始文件：网页内 Excel 展示的是未修改的原工作簿（原始值/公式）+ 问题黄色标记；自动修正结果只用于「修正后值/公式」展示与下载，不再改写被浏览的工作簿。

  • v1.1.0

    网页内定位复核：新增只读 Excel Viewer 两栏工作台，点击问题即可切换 Sheet、定位单元格并查看公式与上下文；支持问题黄色标记、当前选中淡蓝、问题聚焦 / 完整工作表、上一个 / 下一个、名称框与左右拖动调宽。

  • v1.0.2

    版本号展示与迭代记录：页面显示工具版本号与版本迭代说明。

  • v1.0

    基础能力：浏览器本地扫描超过两位小数的单元格，区分原始数据与公式结果，导出修正文件与带 F5 定位的问题清单。
