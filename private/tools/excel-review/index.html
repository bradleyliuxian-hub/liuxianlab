EXCEL REVIEW ASSISTANT

提取批注、生成复核清单、F5 定位。

支持传统 Excel 备注，以及 Microsoft 365 新版线程批注。分析完成后在这里直接显示问题总数、新旧批注分布与问题提出人统计；生成的复核文件第一张表即为 Dashboard（随「回复」自动更新），随后是「新版批注」「旧版批注」两张可自由编辑的清单，每条记录都带 Excel Address（如 '财务复核'!B5），复制到原文件的 F5 / Ctrl+G 定位窗口即可跳转。

每条记录都提供「Excel Address」（例如 '财务复核'!B5）。先打开原始 Excel，按 F5 / Ctrl+G， 粘贴地址即可定位到对应单元格。Review 文件可自由编辑：排序、筛选、新增列、修改显示内容、填写「回复 / 状态」均可； Excel 内 Dashboard 会随「回复」自动更新。系统只生成清单，不回写原文件，也不会读取这些列。
