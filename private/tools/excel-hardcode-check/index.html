EXCEL HARDCODE CHECK

找出疑似被固定数字覆盖的公式与引用。

文件在你的浏览器中读取、扫描与生成，不会上传到服务器。工具通过相邻公式的相对引用模式， 识别被固定值打断的公式序列、被固定值替代的引用，以及公式中额外加入的硬编码数值； 并对一般硬编码给出提示。结果只作疑似提示，请人工核对。

VERSION HISTORY

版本迭代

  • v1.2.6

    网格铺满视口：聚焦模式不再只显示 ±邻域小窗，改为按视口宽高渲染足够行列填满卡片；完整工作表模式随滚动持续扩展虚拟行列，并监听容器尺寸变化（ResizeObserver/分栏拖动）自动补足；空白行列照常显示行号列头。

  • v1.2.5

    可浏览范围扩展：Viewer 不再止步于 used range，自动在数据下方/右侧追加空白网格（+100 行 / +20 列，并按视口高度/宽度动态补足），定位靠边单元格也能居中；仍为虚拟滚动，空白网格不写入 workbook。

  • v1.2.4

    颜色语义区分：问题单元格 = 浅黄（随“显示问题标记”开关）；当前选中/定位单元格 = 淡蓝 + 蓝框；选中且为问题 = 淡蓝 + 蓝框 + 黄色角标，二者清晰可辨。

  • v1.2.3

    定位与自由滚动解耦：定位/上一个/下一个只在动作发生时把镜头移动到目标一次，之后可自由滚动、拖动、点选，不再被拉回；新增「回到当前问题」按钮与可用的名称框定位。

  • v1.2.2

    两栏工作台：删除右侧详情栏，改为「问题列表 + Excel Viewer」两栏，页面接近全宽；问题卡片补充异常常量与核心判断依据；修复左右拖动分隔条，宽度实时生效并保持（可记忆）。

  • v1.2.1

    复核工作台布局：Excel Viewer 成为页面主体（更高更宽，独立滚动），Viewer 与详情间支持拖动调宽；问题详情精简为必要字段并提供「更多详情」折叠；问题卡片收紧，一屏可见更多问题。

  • v1.2.0

    网页内定位复核：新增只读 Excel Viewer，点击问题清单即可切换 Sheet、定位单元格并显示公式/数值与问题依据；支持问题黄色标记开关、问题聚焦与完整工作表（虚拟滚动）、上一个 / 下一个问题。工作簿只读，不修改任何数据。

  • v1.1.0

    标黄对比文件：新增第二个独立下载按钮，基于原始上传文件生成副本，仅对疑似问题单元格添加浅黄填充，供与原文件人工对照。采用 OOXML ZIP 最小补丁，公式、外部链接、命名范围、隐藏状态、图表等保持原样；原文件不被修改。

  • v1.0.0

    基础能力：浏览器本地扫描 .xlsx，通过相邻公式的相对引用模式识别被固定值打断的公式序列、被固定值替代的引用与额外加入的死数；输出 HIGH / 可疑 / 硬编码提示分级与独立检查报告，不修改源文件。
