EXCEL TAIL-RISK CHECK

找到真正可能导致最终展示结果出现尾差的数据。

文件在你的浏览器中读取、分析并生成，不会上传到服务器。工具只发现问题，不会修改原 Excel。 检查的是单元格实际数值而非显示格式，因此「实际值 1.23456、显示 1.23」仍会被识别；尾随 0 与 JS 浮点误差不会误报。 结果按尾差风险分级，并区分普通数值、公式结果、隐藏区域、百分比与汇率（普通数值允许 2 位、汇率允许 4 位）；同一风险等级内按下游引用数从高到低排序，支持网页内定位与问题清单导出。

VERSION HISTORY

版本迭代

  • v1.3.0

    尾差风险分析版：从「异常扫描」升级为「尾差风险分析」。新增隐藏区域可选扫描（隐藏行 / 列 / 工作表，单独分类）、百分比格式独立分析、业务类型识别（普通数值 2 位 / 汇率 4 位 / 疑似汇率与派生不豁免）、汇率纯引用血缘继承（公式等于单个引用即继承汇率、不算公式异常；做了运算即「汇率派生计算」）、公式引用关系（直接引用数 + 去重的下游引用数，支持跨表与循环引用）与风险分级；同一风险等级内按下游引用数从高到低排序，问题清单按类别拆分为 7 个工作表（含汇率检查）且排序一致；风险等级 / 问题类型 / 工作表 / 业务类型 / 隐藏类型 / 精度状态 升级为多选筛选（字段内 OR、字段间 AND、空=全部，工作表可搜索）；Excel 预览内的上一个 / 下一个严格按当前筛选结果与排序移动（不跳到被过滤项、不循环，显示 当前位次/筛选数量）。取消自动修正，仅提供发现、F5 定位与问题清单导出。

  • v1.2.0

    只读复核 + 标黄对比：不再自动修正、不再导出修正版 Excel，也移除「处理状态」；网页内只读展示原始工作簿并标黄问题单元格；新增「下载标黄对比文件」——基于原始文件的最小 OOXML 样式补丁。

  • v1.1.0

    网页内定位复核：新增只读 Excel Viewer 两栏工作台，点击问题即可切换 Sheet、定位单元格并查看公式与上下文。

  • v1.0

    基础能力：浏览器本地扫描超过两位小数的单元格，区分原始数据与公式结果，导出问题清单。
