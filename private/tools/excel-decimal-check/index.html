EXCEL DECIMAL CHECK

检查、修正并导出超过两位小数的单元格。

文件在你的浏览器中读取、扫描与生成，不会上传到服务器。工具检查的是单元格 实际数值而非显示格式，因此「实际值 1.23456、显示 1.23」仍会被判为异常； 尾随 0 不会误报，JS 浮点误差也不会误报。所有结果均可导出为修正后的工作簿，或仅包含问题记录、带 Excel F5 定位地址的问题清单。
